# ウェイソン選択課題（4枚カード問題）

認知心理学の有名な論理パズル「ウェイソン選択課題」のWebアプリケーションです。

## 概要

4枚のカードを使って論理的思考力をテストします。
抽象版と日常版の2つのバージョンで、同じ論理構造でも文脈によって正答率が大きく変わることを体験できます。

## 機能

- **2つのバージョン**:
  - **抽象版**（難しい）: 偶数と母音のルール（正答率：約10%）
  - **日常版**（簡単）: 飲酒年齢のルール（正答率：約75%）
- **バージョン切り替え**: タブで簡単に切り替え可能
- **カード選択**: クリックしてカードを選択
- **正解判定**: 選択したカードが正しいか判定
- **詳細な解説**: なぜその答えが正しいのか、各バージョンごとに詳しく解説
- **内容効果の説明**: なぜ日常的な文脈だと正答率が上がるのか

## 技術スタック

- **Next.js 16.3.5** (App Router)
- **React 19.2.8**
- **TypeScript 5**
- **Tailwind CSS 3**

## セットアップ

### 必要な環境

- Node.js 20以上

### インストール

```bash
npm install --legacy-peer-deps
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:3002 を開きます。

### ビルド

```bash
npm run build
npm start
```

## 使い方

1. 抽象版または日常版を選択
2. ルールを読む
3. 裏返す必要があるカードをクリックして選択
4. 「回答する」ボタンをクリック
5. 正解判定と解説を確認
6. バージョンを切り替えて、もう一度挑戦

## 正解

### 抽象版
**Eと4のカード**を裏返す必要があります。
- **E（母音）**: 裏が偶数であることを確認
- **4（偶数）**: 裏が母音であることを確認

### 日常版
**ビールと17歳のカード**を裏返す必要があります。
- **ビール**: 飲んでいる人が20歳以上かを確認
- **17歳**: ビールを飲んでいないかを確認

## 内容効果（Content Effect）

この2つの問題は論理的には全く同じ構造ですが、正答率が大きく異なります：

- **抽象版の正答率**: 約10%
- **日常版の正答率**: 約75%

人間の脳は抽象的な論理よりも、具体的な社会的ルールや経験に基づいた推論を得意としています。
この現象は「内容効果」と呼ばれ、認知心理学における重要な発見の一つです。
