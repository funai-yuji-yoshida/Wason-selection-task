# ウェイソン選択課題（4枚カード問題）

認知心理学の有名な論理パズル「ウェイソン選択課題」のWebアプリケーションです。

## 概要

4枚のカードを使って論理的思考力をテストします。
「カードの片面が偶数ならば、もう片面は母音である」というルールを検証するために、
どのカードを裏返す必要があるかを考える課題です。

## 機能

- **4枚カードの表示**: E, K, 4, 7
- **カード選択**: クリックしてカードを選択
- **正解判定**: 選択したカードが正しいか判定
- **詳細な解説**: なぜその答えが正しいのか、詳しく解説

## 技術スタック

- **Next.js 16.3.5** (App Router)
- **React 19.2.8**
- **TypeScript 5**
- **Tailwind CSS 3**

## セットアップ

### 必要な環境

- Node.js 20以上

### インストール

```bash
npm install --legacy-peer-deps
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:3002 を開きます。

### ビルド

```bash
npm run build
npm start
```

## 使い方

1. ルールを読む
2. 裏返す必要があるカードをクリックして選択
3. 「回答する」ボタンをクリック
4. 正解判定と解説を確認
5. 「もう一度挑戦」で再チャレンジ

## 正解

**Eと4のカード**を裏返す必要があります。

- **E（母音）**: 裏が偶数であることを確認
- **4（偶数）**: 裏が母音であることを確認
